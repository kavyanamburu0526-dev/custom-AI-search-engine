🔎 Custom AI Search Engine
An AI-powered search engine built using Python, Tavily and Google Gemini.
🚀 Features
- Real-time web search using Tavily
- AI-generated answers using Gemini
- Displays source links
- API keys stored securely using .env
- Command-line interface
🛠️ Technologies
- Python
- Tavily API
- Google Gemini API
- python-dotenv
🔄 How It Works
User Query
    ↓
Tavily Web Search
    ↓
Search Results
    ↓
Gemini LLM
